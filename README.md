## Sobre o projeto

Este é um **exercício acadêmico de planejamento estratégico e design visual**, desenvolvido para a Escola Zion.

A proposta foi identificar uma dificuldade fictícia do Buffet Dona Lurdes — poucos pedidos de orçamento mesmo com um serviço de qualidade — e criar uma solução de apresentação mais clara, acolhedora e fácil de entender.

O projeto trabalha a estrutura:

- **Dor:** clientes não entendem com clareza os produtos, serviços e diferenciais.
- **Oportunidade:** melhorar a comunicação para gerar confiança e mais pedidos.
- **Solução:** site responsivo, cardápio organizado, fotos dos produtos e contato facilitado.

Projeto demonstrativo criado com HTML, CSS e JavaScript puro.

- `index.html`: site principal responsivo.
- Cardápio completo integrado ao próprio site.

> Contato e endereço são fictícios. Valores sob consulta. Este projeto não representa um buffet real.
